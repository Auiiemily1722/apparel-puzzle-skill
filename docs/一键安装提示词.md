# 一键安装提示词 + 操作介绍（新电脑 · 豆包 Work）

## 一、使用方法

1. 新电脑准备：Python 3.9+（安装时勾选 "Add to PATH"）。获取方式为 git clone，需先装 git（提示词会自动检查并安装）；
2. 把下面「提示词」整段复制，发给豆包 Work 的 agent；
3. agent 会自动完成获取、配置、自检并汇报结果；
4. 安装完成后，打开项目文件夹，直接发图即可使用（图片无需任何文字说明）。

## 三、操作介绍（安装完成后怎么用）

**一句话**：打开项目文件夹 → 直接发 透明底 logo + 衣服原图 → 收到 透明底拼图PNG + 分图层PSD 两个文件 → 产物自动存到 `output/时间戳/`。

| 环节 | 说明 |
|---|---|
| 安装 | git clone（GitHub 首选 `https://github.com/Auiiemily1722/apparel-puzzle-skill.git`；连不上则 Gitee 镜像 `https://gitee.com/image-matting-skill/apparel-puzzle-skill.git` 国内免代理；都失败则联系管理员索取压缩包源文件）。随后运行 `scripts/setup.ps1`（建目录、装依赖） |
| 素材准备 | logo / 字符图必须是透明底（先在「抠图测试」项目抠好）；衣服原图不用抠，发来什么样就什么样 |
| 使用 | 对话窗直接发 2~4 张图（logo / 字符 + 衣服原图）+ 一串序列号（文字或图片均可），agent 自动执行：视觉识别角色 → 提取序列号 → 智能布局（logo 左侧大图、衣服右下角小图）→ 合成 PNG → 生成 PSD → 交付 → 归档 |
| 布局规则 | 单 logo 居中占主区；1 logo + 字符 → 主 logo 在上、字符在下垂直堆叠；2 个 logo → 50:50，按 logo 现状智能排布（均横向→上下堆叠，其余→左右并排）；画布比例智能自适应 |
| 交付 | 每次同时给 `序列号_puzzle.png`（透明底合成图）和 `序列号_puzzle.psd`（PS 可打开，**分图层**：每张上传图独立一层——Original 衣服原图 / Logo-1、Logo-2… 每个印花各一层 / Text-1… 每个字符各一层 / Composite 合成预览；无序列号回退用衣服原图名） |
| 归档 | `output/YYYYMMDD_HHMMSS/` 内放这批图的 PNG+PSD（每批任务独立文件夹），不覆盖 |
| 换设备 | 任何新电脑重复「一、使用方法」即可，项目本身通过 GitHub / Gitee 同步 |

**注意**：本项目面向「支持多模态视觉识别」的 agent（能看图区分 logo 与衣服）。不带视觉识别能力的 agent（如普通编码 agent）无法执行核心的"角色识别"步骤。

## 四、GitHub ↔ Gitee 双远程同步

- Gitee 的「从 GitHub 导入」是一次性快照，**不会自动同步** GitHub 后续更新。
- 推荐做法（本机已配好两个远程 origin=GitHub、gitee=Gitee）：
  ```powershell
  git push origin main   # 推 GitHub
  git push gitee main    # 推 Gitee（首次会弹登录框：用户名 image-matting-skill + 密码/私人令牌）
  ```
- 或启用 Gitee「管理 → 仓库镜像管理」从 GitHub 定时同步（需 GitHub 账号令牌）。
