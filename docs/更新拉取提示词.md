# 更新/拉取提示词（已装过项目的电脑 · 抓取远程最新进度）

> 用途：让另一台电脑的 agent 把「服饰印花拼图技能项目（apparel-puzzle-skill）」更新到远程仓库最新进度。
> 已装过 → `git pull` 增量更新；没装过 → 自动按优先级 clone 安装。
> 双远程内容一致（GitHub 与 Gitee 同步），任一路径拉到即是最新。

## 使用方法

把下面「提示词」整段复制发给 agent，agent 会自动判断项目是否存在并完成更新/安装，随后汇报结果。

## 提示词（复制整段发给豆包 Work）

```
请把我电脑上的「服饰印花拼图技能项目（apparel-puzzle-skill）」更新到远程仓库的最新进度。

按以下顺序执行，每一步都要检查结果；只有前一条失败才降级，不得绕过失败假装成功。

0. 环境检查（先确认网络与工具）：
   - git 是否可用：git --version（不可用 → 提示先安装 git：Windows 优先 winget install Git.Git，或从 git-scm.com 下载；安装失败则明确告知无法自动更新）。
   - 网络连通性：git ls-remote https://github.com/Auiiemily1722/apparel-puzzle-skill.git（能连通即可，无需登录）。
   - GitHub 不通 → 再试 Gitee：git ls-remote https://gitee.com/image-matting-skill/apparel-puzzle-skill.git。

1. 判断项目是否已在本机（关键）：
   - 在本机查找 apparel-puzzle-skill 文件夹（默认在桌面/工作目录下；找不到可询问用户位置）。
   a) 项目已存在 → 进入项目目录，执行 git pull（使用原远程）：
      - pull 失败（网络被重置/超时）→ 配置代理后重试：git config http.proxy http://127.0.0.1:7897（或询问用户代理地址；若用户有代理/VPN 需手动开启，提示开启后再试）。
      - 直连与代理都失败 → 换另一远程拉取：原远程是 GitHub 就用 Gitee 仓库地址拉（git pull https://gitee.com/image-matting-skill/apparel-puzzle-skill.git main）；原远程是 Gitee 就用 GitHub 仓库地址拉（git pull https://github.com/Auiiemily1722/apparel-puzzle-skill.git main）。
      - 全部失败 → 立即停止，明确告知用户："当前设备无法连接 GitHub 与 Gitee 远程仓库，无法更新项目。请稍后重试或开启代理/VPN。"不得伪造或跳过更新。
   b) 项目不存在 → 按优先级 clone 安装：
      1) GitHub 直连：git clone https://github.com/Auiiemily1722/apparel-puzzle-skill.git
      2) 失败 → 配置代理重试（同上代理设置）；
      3) 仍失败 → Gitee 镜像（国内免代理）：git clone https://gitee.com/image-matting-skill/apparel-puzzle-skill.git
      4) 全部失败 → 停止并告知无法获取项目，请稍后重试或开启代理/VPN。
      - clone 完成后进入项目目录，运行 scripts/setup.ps1（建目录、装 Python 依赖：Pillow + psd-tools；需要 Python 3.9+，未安装则提示用户安装并勾选 Add to PATH 后重跑）。
   - 成功后汇报：本次更新/安装到哪个提交（git log -1 --oneline）、通过「GitHub 直连 / GitHub+代理 / Gitee 镜像」中的哪条路径；之后需要更新时再发本提示词，用 git pull 即可。

2. 验证更新结果（关键步骤，不要跳过）：
   - git log --oneline -3 查看最近提交，确认是最新版；
   - 确认关键文件存在：NAVIGATION.md / AGENTS.md / README.md / config/skill.config.json / skill/SKILL.md / skill/scripts/layout.py / skill/scripts/compose_puzzle.py / skill/scripts/build_psd.py / docs/一键安装提示词.md；
   - 本次 pull 若更新了 requirements.txt，重跑 scripts/setup.ps1 刷新依赖（默认不重跑，除非依赖文件有变化）。

3. 收尾汇报：
   - 汇报当前版本号与最近提交说明、更新路径、关键文件完整性检查结果；
   - 简要提示最新用法：用户在对话窗直接发 透明底 logo/印花（1~2 张，可带字符图）+ 衣服原图 + 一串英文/数字序列号，agent 自动拼图并交付 序列号.png + 序列号.psd（PSD 每张上传图独立一层，无合成预览层；文件名只留编号不加后缀），产物归档到 output/时间戳/ 文件夹。
```

## 常见情况说明

| 情况 | 行为 |
|---|---|
| 已装过项目 | 直接 `git pull` 增量更新，几秒完成；不重装、不覆盖 input/output |
| 新电脑/项目不存在 | 自动按「GitHub 直连 → 代理 → Gitee 镜像」clone，并运行 setup.ps1 初始化 |
| GitHub 连不上 | 自动走代理或 Gitee 镜像（国内免代理） |
| 都连不上 | 停止并明确告知，不伪造成功 |

## 换电脑后的首次使用

更新完成后即可直接使用：打开项目文件夹 → 发 透明底 logo/印花 + 衣服原图 + 序列号 → 收 序列号.png/.psd（只留编号，不加后缀）。
